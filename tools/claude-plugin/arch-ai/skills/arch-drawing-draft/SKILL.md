# 도면 작도

## 절차

1. **설계 조건 정리** — 용도, 층수, 필요 실과 면적, 대지 크기·방위, 구조 모듈(그리드 간격), 벽 두께.
   법적 한계(건폐율·용적률·이격거리·높이)가 걸리면 먼저 `arch-building-code`로 한계값을 확인한다.
2. **작도 스펙(JSON) 작성** — 단위 mm, 원점은 좌하단 그리드 교점. 형식은 아래 참고.
3. **작도** — MCP `dxf_draw(spec_json, out_path)` 또는 `archai dxf draw spec.json out.dxf`.
4. **자가 검증 (필수)** — `dxf_inspect`로 다시 읽어서:
   - 실 면적 합 ≈ 요구 면적, 방별 면적이 요구 조건을 만족하는가
   - 치수 측정값이 스펙과 같은가, 레이어가 표준대로 분리됐는가
   - 문 개폐 방향이 피난 방향·가구 배치와 충돌하지 않는가
5. **산출** — DXF + 작도 스펙 JSON을 함께 저장한다(스펙이 곧 설계 근거). 한계(벽 접합부 미정리 등)를 보고에 적는다.

## 작도 스펙 형식

```json
{
  "title": "1층 평면도", "scale": "1/100", "text_height": 250,
  "grids": {"x": [0, 7200, 14400], "y": [0, 6000, 12000], "labels_x": ["X1","X2","X3"], "labels_y": ["Y1","Y2","Y3"]},
  "walls": [{"path": [[0,0],[14400,0],[14400,12000],[0,12000],[0,0]], "thickness": 200}],
  "doors": [{"at": [3600, 0], "width": 900, "angle": 0, "swing": "in"}],
  "windows": [{"at": [10800, 0], "width": 2400, "angle": 0}],
  "rooms": [{"name": "사무실", "boundary": [[0,0],[7200,0],[7200,6000],[0,6000]]}],
  "dims": [{"p1": [0,0], "p2": [7200,0], "offset": -1500}]
}
```
- `walls.path`: 벽 중심선, `thickness`: 벽 두께. `doors/windows.at`: 벽 중심선 위 개구부 중심점, `angle`: 벽 방향(도).
- `rooms.boundary`: 실 경계(면적 계산 기준). 법정 면적 산정 기준(벽 중심선 등)에 맞춰 경계를 잡는다.

## 레이어 표준 (도구 기본값)

`S-GRID`(그리드, CENTER 선), `A-WALL`, `A-DOOR`, `A-GLAZ`, `A-AREA-IDEN`(실 경계), `A-ANNO-DIMS`, `A-ANNO-TEXT`, `A-ANNO-TTLB`.
프로젝트에 레이어 표준이 따로 있으면 작도 후 레이어 이름을 바꿔 맞춘다.

## 설계 실무 기준값 (초안용 출발점 — 법규 확인 전 가정값으로만 사용)

| 항목 | 흔한 값 |
|---|---|
| 구조 그리드 (RC 사무소/상가) | 7.2 ~ 9.0 m |
| 구조 그리드 (공동주택 벽식) | 실 구성 따라 가변 |
| 외벽 두께 (RC + 단열 + 마감) | 구조체 200 + 단열 + 마감 (지역별 단열 기준 확인) |
| 내벽 (경량/조적) | 100 ~ 200 |
| 출입문 폭 | 주출입 900 ~ 1,800, 실 출입 900, 화장실 800 |
| 복도 유효폭 | 용도·규모별 법정 최소값 있음 → arch-building-code |
| 계단 | 단높이·단너비·유효폭·참 규정 → arch-building-code |

## DXF 수정 작업

기존 도면을 고칠 때는 ezdxf로 직접 스크립트를 작성한다(원본은 보존, 새 파일로 저장):
```python
import ezdxf
doc = ezdxf.readfile("in.dxf"); msp = doc.modelspace()
for e in msp.query('TEXT MTEXT[layer=="A-ANNO-TEXT"]'):
    ...  # 실명 변경 등
doc.saveas("out.dxf")
```
재사용할 만한 스크립트는 허브 저장소 `tools/scripts/`에 저장하고 목록에 추가한다.

## 한계

도구의 작도는 **초안** 수준이다: 벽 접합부 정리, 해치, 입면·단면 자동 생성, 도면 출력(플롯) 설정은 하지 않는다.
실시설계 도면은 CAD/BIM 저작 도구에서 마무리하도록 안내한다.
