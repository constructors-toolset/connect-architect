# 구조 해석·검토·오류 정정

## 원칙

- 기준: KDS 41(건축구조기준), KDS 14 20(콘크리트구조), KDS 14 30/41 30(강구조) — 개정판을 kcsc.re.kr에서 확인.
  법령 측면(구조안전 확인 대상 등)은 `arch-building-code`.
- 모든 검토는 **계산식·입력값·기준 조항**을 함께 보인다. 계산은 손으로 하지 말고 도구로 한 뒤 크기를 상식으로 검증한다.
- 결과는 **예비 검토**다. 구조 안전 판단의 최종 책임은 구조기술사에게 있음을 보고서에 명시한다.

## 도구 (단위: mm, MPa, kN, kN/m, kN·m)

| 목적 | MCP | CLI |
|---|---|---|
| 하중조합 (KDS 41 10 15) | `struct_load_combinations(D, L, Lr, S, R, W, E, ...)` | `archai structure combos --D 5 --L 3` |
| 보 해석 M/V/처짐 | `struct_beam(span, w, P, a, support, E, I)` | `archai structure beam --span 6000 --w 25` |
| RC 보 휨·전단 | `struct_rc_beam(b, d, fck, fy, As, Mu, Vu, Av, s)` | `archai structure rc-beam ...` |
| 최소두께 (처짐 미계산) | `struct_min_depth(member, span, support, fy, h)` | `archai structure min-depth ...` |

골조 전체 해석(부정정 골조, 지진·풍하중 동적해석)은 이 도구 범위를 넘는다. 필요하면 파이썬으로
직접 강성행렬 해석 스크립트를 작성하거나(재사용 시 `tools/scripts/`에 저장), 상용 프로그램(MIDAS 등) 결과 파일을 읽어 검토한다.

## 검토 절차

1. **입력 확인**: 구조형식, 재료 강도(fck, fy), 부재 일람표(단면·배근), 경간, 지지조건, 용도별 활하중, 마감 하중.
2. **하중 산정**: 고정하중 = 구조체 자중(RC 단위중량 24 kN/m³) + 마감·설비·칸막이. 활하중은 KDS 41 10 15 용도별 표에서.
   바닥하중(kN/m²) × 부담폭 → 보 등분포하중(kN/m). 슬래브 자중 누락이 가장 흔한 실수다.
3. **하중조합**: 지배 조합의 계수하중으로 단면력을 구한다.
4. **단면 검토**: 휨(φMn ≥ Mu), 전단(φVn ≥ Vu), 최소·최대 철근, 최소두께/처짐, 스터럽 간격.
5. **상식 검증**: 결과를 경험값과 비교한다([references/rules-of-thumb.md](references/rules-of-thumb.md)).
6. **오류·정정안 보고**.

## 흔한 오류 유형 (도면·계산서 검토 시 우선 확인)

| 유형 | 예 | 정정 방향 |
|---|---|---|
| 하중 누락 | 슬래브 자중, 마감, 조적 벽체 선하중, 설비 하중 누락 | 하중표 재작성 |
| 단위 오류 | kN/m² ↔ kN/m 혼동, 부담폭 미적용, mm²↔cm² | 차원 검사 |
| 유효깊이 오류 | d = h − 피복만 빼고 스터럽·주근 반지름 누락 | d = h − 피복 − 스터럽 − db/2 |
| 철근량 | 일람표 개수 × 단면적 계산 오류, 최소철근 미달 | As 재계산 |
| 연성 부족 | εt < 최소 허용변형률 (과보강) | 단면 확대 또는 압축철근 |
| 전단 | 스터럽 간격이 s_max 초과, 최소 전단철근 누락 | 간격 축소 |
| 처짐 | 최소두께 미달인데 처짐 계산 없음 | 두께 증가 또는 처짐 계산 |
| 도면 불일치 | 구조계산서 단면 ≠ 구조도면 일람표 ≠ 건축도면 | 기준 문서 확정 후 일괄 정정 |
| 개구부 | 보 춤의 과도한 관통, 슬래브 개구부 보강 누락 | 보강 상세 추가 |
| 정착·이음 | 정착길이·이음 위치(최대 응력부 이음) | KDS 14 20 52 확인 |
