# 건축 도면 표기 규약 요약

> 국내 실무 관행 기준 요약. 사무소별 표준(범례)이 있으면 그것이 우선한다.
> 관련 표준: KS F 1501(건축 제도 통칙), KS A 0106/0111 계열(제도 통칙·도면 크기) — 최신판 확인.

## 선의 종류

| 선 | 용도 |
|---|---|
| 굵은 실선 | 단면선(잘린 벽·기둥·슬래브), 외형선 |
| 중간 실선 | 입면에서 보이는 외형, 문·창틀 |
| 가는 실선 | 치수선, 치수보조선, 인출선, 해치, 마감선 |
| 파선(점선) | 숨은선: 보이지 않는 부분, 상부 보·천장 개구부, 철거 부분 |
| 1점쇄선 | 중심선, 그리드(통심선), 대지경계선(굵은 1점쇄선) |
| 2점쇄선 | 가상선, 이동 위치, 인접 대지 건물 |

## 도면 크기·축척

- 도면 크기: A0(841×1189), A1(594×841), A2(420×594), A3(297×420) mm.
- 흔한 축척: 배치도 1/200~1/600, 평·입·단면 1/100~1/200, 부분상세 1/20~1/50, 상세 1/5~1/10.
- 도면이 축소 출력되면 축척이 달라진다(A1 원도를 A3로 출력하면 1/100 → 1/200). 스케일바가 있으면 우선.

## 주요 기호

| 기호 | 의미 |
|---|---|
| ○ 안 X1/Y1 | 그리드 번호 |
| ▽ + 숫자 | 레벨 (예: ▽FL+3,600) |
| 원 안 번호/도면번호 | 단면 표시(절단 위치·방향), 상세 인용 |
| 삼각 구름 + 번호 | 개정 표시 |
| 북측 화살표(N) | 방위 |
| UP/DN 화살표 | 계단·경사로 오름/내림 방향 |
| EXP.J | 신축줄눈 |

## 해치(재료 표시) — 단면

| 해치 | 재료 |
|---|---|
| 45° 사선 + 점 | 철근콘크리트 |
| 45° 사선 | 벽돌·조적 |
| 점 무늬 | 모르타르, 모래 |
| 파형·물결 | 단열재 |
| 나뭇결 | 목재 |
| 굵은 사선 격자 | 잡석·자갈 |
| 흑색 채움 | 철골(작은 축척) |

| 약어 | 의미 | 약어 | 의미 |
|---|---|---|---|
| FL | 바닥 마감 레벨 | CH | 반자(천장) 높이 |
| SL | 구조체 슬래브 레벨 | GL | 지반 레벨 |
| THK / T | 두께 | @ | 간격 |
| EA | 개수 | TYP. | 공통(전형) |

| C.L / ℄ | 중심선 | O.C. | 중심 간격 |

| DN / UP | 내림 / 오름 | EXP.J | 신축줄눈 |
| PS | 파이프 샤프트 | EPS/TPS | 전기/통신 샤프트 |

## 구조 도면 부재 기호 (일반적)

| 기호 | 부재 | 비고 |
|---|---|---|
| C, SC | 기둥, 철골 기둥 | C1, C2… 일람표 대응 |
| G, TG, SG | 큰보, 전이보, 철골 큰보 | 층 접두어: 2G1 = 2층 G1 |
| B, SB | 작은보, 철골 작은보 | |
| S | 슬래브 | 두께·배근 일람 |
| W, SW | 벽, 전단벽 | |
| F, MAT | 독립기초, 매트기초 | |
| HD | 앵커(홀다운) 등 | |

배근 표기 예: `4-HD22` = 고강도(SD400 이상) D22 4개, `HD10@200` = D10 200 간격,
`D13@150 (상·하)` = 상하단. HD/D 접두어 의미는 도면 일반사항(구조 노트)을 확인한다.

## 면적 용어 (법규 연계 — 산정 기준은 건축법 시행령 제119조 확인)

건축면적, 바닥면적, 연면적, 대지면적, 전용면적, 공용면적, 서비스면적(발코니)은 산정 방법이 서로 다르다.
도면 면적표를 검토할 때는 각 면적이 어느 정의에 따른 값인지 먼저 확인한다.
