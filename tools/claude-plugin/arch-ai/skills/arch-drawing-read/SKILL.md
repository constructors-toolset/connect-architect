# 도면 판독·해석

## 1. 먼저 도면 세트를 파악한다

1. **도면 목록표·도곽**에서 프로젝트명, 도면번호, 축척, 개정(Rev) 번호·일자를 읽는다.
2. 도면번호 접두어로 분야를 구분한다 (예: A 건축, S 구조, M 기계, E 전기, P 위생, F 소방, C 토목, L 조경).
   번호 체계는 사무소마다 다르므로 도면목록표를 우선한다.
3. 판독 순서: 배치도 → 면적표/개요 → 평면도(층별) → 입면도 → 단면도 → 상세도 → 일람표(창호·마감·부재).

## 2. 파일 유형별 방법

| 입력 | 방법 |
|---|---|
| DXF | `dxf_inspect`(MCP) 또는 `archai dxf inspect file.dxf --texts` → 단위, 레이어별 요소, 폐합 폴리라인 면적, 치수값, 문자 |
| DWG | ODA File Converter 등으로 DXF 변환 후 위와 같이 |
| PDF (벡터) | pdf 스킬로 텍스트·표 추출(도면목록, 면적표, 일람표) + 페이지 이미지로 시각 판독 |
| PDF (스캔)/이미지 | 시각 판독. 치수는 도면에 적힌 값만 신뢰하고 자로 재지 않는다(축척 왜곡) |

DXF 해석 요령: `units`가 unitless면 치수값 크기로 mm/m를 추정하고 그 사실을 적는다.
레이어 이름의 `hint`로 벽/문/창/그리드를 구분하되, 레이어가 엉망인 도면이 많으므로 블록 이름·문자로 교차 확인한다.
실 면적은 `A-AREA`/`ROOM` 계열 폐합 폴리라인 면적과 도면의 면적표 값을 대조한다.

## 3. 읽는 법 (핵심 규약)

자세한 기호·선·해치 규약은 [references/conventions.md](references/conventions.md) 참고.

- **치수**: 국내 건축 도면 기본 단위는 mm. 레벨은 `FL`(마감), `SL`(구조체), `GL`(지반), `EL`/`▽` 표기, 단위 mm 또는 m 확인.
- **그리드(통심선)**: 가로 X1, X2… / 세로 Y1, Y2… 또는 1, 2… / A, B…. 모든 분야 도면의 그리드 간격이 같아야 한다.
- **벽 두께**: 치수가 중심선 기준인지 마감면 기준인지 확인. 구조체와 마감을 구분한다.
- **창호**: 창호 기호(예: AW 알루미늄창, SD 강재문, WD 목재문, PD 방화문 등 — 사무소별 상이)를 창호일람표와 대조.
- **단면도**: 층고 = 바닥 마감 ~ 윗층 바닥 마감. 반자높이(CH)와 구분.
- **구조 도면**: 부재 기호(C 기둥, G 큰보, B 작은보, S 슬래브, W 벽, F 기초)와 부재 일람표의 단면·배근을 대응.

## 4. 도면 검토 체크리스트

- [ ] 도면 간 그리드·치수 일치 (평면 ↔ 입면 ↔ 단면 ↔ 구조)
- [ ] 치수 합계 = 전체 치수 (부분 치수 합이 전체와 맞는가)
- [ ] 층고·레벨이 단면도·입면도·평면 레벨 표기와 일치
- [ ] 문·창 개수·크기가 평면도와 창호일람표에서 일치
- [ ] 실명·면적이 평면도와 면적표에서 일치, 면적 합계가 층 바닥면적과 일치
- [ ] 계단: 단높이·단너비·유효폭·난간 높이 표기 (법규 기준은 arch-building-code로 확인)
- [ ] 방화구획선, 방화문 등급, 피난 동선 표시
- [ ] 개정 구름(Revision cloud)과 개정 이력 일치, 최신 Rev 사용 여부
- [ ] 구조 개구부(슬래브·보 관통)와 설비 도면 슬리브 위치 일치

## 5. 보고 형식

```
## 도면 판독 결과: <도면번호/이름> (Rev.x, 축척 1/xxx)
- 개요: 용도, 층수, 구조형식, 주요 치수
- 실 구성/면적표: (도면 기재값 / 계산값 / 차이)
- 불일치·오류: [심각도 높음/중간/낮음] 위치(그리드·실명) — 내용 — 근거 도면
- 확인 필요 사항: 판독 불가·정보 누락
```
판독값과 추정값을 구분해서 적는다(`확인됨`/`추정`).
