# 시방서 작성·검토

## 시방서 체계

| 구분 | 내용 | 작성 주체 |
|---|---|---|
| 표준시방서 (KCS) | 공종별 표준 시공기준. 국가건설기준센터(kcsc.re.kr)에서 코드로 관리 | 국토교통부/기준 관리기관 |
| 전문시방서 | 발주기관별 표준 (예: 조달청, LH 전문시방서) | 발주기관 |
| 공사시방서 | 특정 공사용. 표준·전문시방서를 기본으로 공사 특성 반영 | 설계자 |
| 특기시방서 | 공사시방서 중 표준과 다르거나 추가되는 사항 | 설계자 |

**우선순위**는 계약 문서(공사계약 일반조건, 설계도서 해석 우선순위 규정)를 따른다. 일반적으로 특기시방이 표준보다 우선하며,
설계도서 간 상충 시 해석 순서는 계약 문서마다 다르므로 해당 공사의 계약 조건을 확인한다.

## KCS 코드 구조

`KCS AA BB CC` — AA 분야(예: 14 공통/일반, 41 건축), BB 중분류, CC 세분류.
표준시방서는 보통 **1. 일반사항 / 2. 자재 / 3. 시공** 3부 구성이다.
코드는 개정·통폐합되므로 작성 전에 kcsc.re.kr에서 현행 코드와 제목을 확인하고, 시방서에 **참조 기준의 코드·버전(연도)** 을 적는다.
(도구의 BOM 기본 품목에 적힌 `kcs_ref`는 출발점 예시다. 실제 사용 전에 코드를 확인한다.)

## 도구

| 목적 | MCP | CLI |
|---|---|---|
| 공사시방서 골격(3부 구성) 생성 | `spec_skeleton(title, kcs)` | `archai spec skeleton "철근콘크리트공사" --kcs "KCS 14 20 00"` |
| 시방서 ↔ BOM 교차검토 | `spec_check(spec_path)` | `archai spec check spec.md` |
| 자재 코드 조회 | `bom_search(keyword)` | `archai bom search 방수` |
| 관련 법령·고시 | `law_search(..., target="admrul")` | |

## 작성 절차

1. **공종 목록 작성** — 도면(마감표·일람표)과 BIM 재료에서 공종을 뽑는다(가설, 토공, 철근콘크리트, 철골, 조적, 방수, 단열, 미장, 타일, 석공, 목공, 수장, 창호·유리, 도장, 지붕, 금속 등).
2. **공종별 골격 생성** — `spec_skeleton`으로 3부 구성 골격을 만든다.
3. **내용 작성** — 절마다 아래를 채운다.
   - 일반사항: 적용범위, 참조 표준(KS·KCS 코드와 연도), 제출물, 품질보증, 운반·보관
   - 자재: 품명·규격·성능(강도, 내화, 단열 열관류율, 방수 등급 등)·KS 번호·**BOM 코드**
   - 시공: 순서, 허용오차, 양생·보양, 검사 항목·빈도·판정 기준
4. **특기사항 표시** — 표준과 다른 내용은 "특기시방"으로 표시하고 이유를 적는다.
5. **교차검토** — `spec_check`로 BOM 코드 누락을 확인하고, 아래 대조를 한다.

## 도면·BOM 대조 체크리스트

- [ ] 도면 마감표의 모든 재료가 시방서 자재 절에 있다 (반대로 시방서에만 있는 자재는 없는가)
- [ ] 도면 성능 표기(방화문 등급, 단열 두께·열관류율, 콘크리트 강도, 철근 종류)가 시방서와 같다
- [ ] 법정 성능(내화구조, 단열 기준, 방화재료)이 시방서 요구 성능 이상이다 → arch-building-code
- [ ] 시방서 자재가 BOM 코드로 연결되고 규격이 같다 → arch-bom-cost
- [ ] 시험·검사 빈도가 명시되어 있다 (콘크리트 압축강도, 철근 인장, 방수 담수시험 등)

## 문장 작성 규칙

- 의무는 "~하여야 한다", 권장은 "~하는 것이 좋다", 선택은 "~할 수 있다"로 구분한다.
- "적정한", "충분히" 같은 모호한 표현 대신 수치·기준·검사 방법을 쓴다.
- 특정 상표명 지정을 피하고 성능으로 규정한다(불가피하면 "동등 이상").
- 저장 위치: 허브 저장소 규칙에 따라 `docs/design/spec-<공종>.md` (front matter `author: ai`).
