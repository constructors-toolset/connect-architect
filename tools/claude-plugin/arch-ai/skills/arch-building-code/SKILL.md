# 건축 법규 검색·검토

## 핵심 원칙

1. **기억으로 수치를 말하지 않는다.** 법령은 자주 개정된다. 수치·조건은 반드시 `law_article`/`law_search`로
   현행 조문을 조회하고, 답변에 **법령명 + 조항 + 시행일자**를 붙인다.
2. **상위법 → 하위법 → 조례 순으로 확인한다.** 건축법이 기준을 시행령에 위임하고, 시행령이 조례에 위임하는 구조가 많다.
   예: 건폐율·용적률 = 국토계획법 제77·78조(상한) → 시행령 제84·85조(용도지역별 범위) → **도시계획 조례(실제 적용값)**.
3. **지역 규제는 법령 검색만으로 끝나지 않는다.** 지구단위계획, 경관지구, 고도지구 등은 토지이음(eum.go.kr) 토지이용계획확인서로
   확인해야 한다. 이 도구로 확인할 수 없으면 "확인 필요"로 표시하고 사용자에게 요청한다.

## 도구

| 목적 | MCP | CLI |
|---|---|---|
| 핵심 법령 목록 | `law_core_list` | `archai law core` |
| 법령 검색 | `law_search(query, target="law")` | `archai law search 건축법` |
| 조문 조회 | `law_article("건축법", "44")` | `archai law article 건축법 44` |
| 조례 검색 | `law_search("서울특별시 건축 조례", target="ordin")` | `--target ordin` |
| 고시·훈령 | `target="admrul"` (예: 건축물의 에너지절약설계기준) | `--target admrul` |
| 판례 / 법령해석례 | `target="prec"` / `target="expc"` | |

환경변수 `LAW_OC`(국가법령정보센터 Open API 계정)가 필요하다. 없으면 사용자에게 open.law.go.kr 신청을 안내한다.

## 검토 절차

1. **전제 조건 확정**: 대지 위치(시·군·구), 용도지역·지구, 대지면적, 도로 조건(폭·접도 길이), 건축물 용도(시행령 별표 1 분류), 규모(층수·연면적·높이).
2. **체크리스트 순회**: [references/checklist.md](references/checklist.md)의 항목 중 해당하는 것을 고른다.
3. **조문 조회**: 항목마다 근거 조문을 조회해 기준값을 읽는다. 위임 조문이면 하위 법령·조례까지 따라간다.
4. **설계값 대조**: 도면 면적표·치수(arch-drawing-read) 또는 BIM(arch-bim-ifc)에서 설계값을 가져와 비교한다.

## 자주 틀리는 부분

- 면적 산정(건축면적·바닥면적·연면적·높이·층수)은 건축법 시행령 제119조의 산정 방법을 따른다 — 발코니, 필로티, 지하층, 다락, 옥탑 처리 확인.
- 용도 분류는 시행령 별표 1. 같은 "근린생활시설"도 1종/2종, 면적 합계에 따라 달라진다.
- 주차 대수는 주차장법 시행령 별표 1과 **지자체 주차장 조례**(강화 가능)를 모두 확인.
- 피난·방화는 「건축물의 피난ㆍ방화구조 등의 기준에 관한 규칙」과 소방시설법을 함께 본다.
- 개정 경과규정(부칙)에 따라 허가 신청 시점 법령이 적용될 수 있다 → 적용 시점 확인.
