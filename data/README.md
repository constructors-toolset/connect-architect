# data

| 폴더 | 내용 | 규칙 |
|---|---|---|
| `raw/` | 수집한 원본 데이터 | **수정 금지**, 출처와 수집일을 기록 |
| `external/` | 외부 공개 데이터셋 | 라이선스와 다운로드 URL을 기록 |
| `processed/` | 정제·가공된 데이터 | 어떤 원본에서 어떤 스크립트로 만들었는지 기록 |
| `generated/` | AI가 생성한 데이터 (합성 데이터, 추출·분석 결과 등) | 같은 이름의 `.meta.md`에 생성 정보 기록 |

|---|---|---|---|

## 주의
- 50MB가 넘는 파일은 커밋하지 않고, 저장 위치와 받는 방법만 적습니다.
- 개인정보가 포함된 데이터는 저장하지 않습니다.

## `.meta.md` 예시 (`data/generated/`)

```markdown
- 생성일: 2026-09-23
- 생성 주체: AI (모델/도구 이름)
- 입력: data/processed/xxx.csv
- 방법: tools/scripts/xxx.py 또는 사용한 프롬프트(tools/prompts/xxx.md)
- 설명: 무엇을 담고 있는지, 알려진 한계
```
